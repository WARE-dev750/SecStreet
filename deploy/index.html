How it works

Find

Search by what a capability does — parsing, enumeration, analysis — not by repository name.

Verify

Every install is hashed and, for higher trust tiers, signed with a verified key.

Compose

Chain capabilities in workflows. Output of one feeds the input of the next.

Get started

Install the CLI to run capabilities on your own machine.

npm i -g @secstreet/sdk
secstreet init my-project
secstreet search elf
